# Sources exactes du banc execute

Ces copies documentent les sondes et contrepreuves executees dans le dossier jetable indique par les recus.
Elles ne sont pas des commandes d'installation. Les chemins ROOT des scripts supposent le banc original conserve.
Ne pas les executer depuis ce dossier archive ni les pointer sur une installation active.
`native_token_probe.py` utilise le jeton primaire ouvert sur le vrai PID API, puis revertit toujours son impersonation.
`qualify_native.py` garde les profils et les preuves, restaure les octets canaris et ne termine que les processus appartenant au banc.
Les cles privees, les registres et le contenu financier operationnel ne sont pas inclus.
